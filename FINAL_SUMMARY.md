## 🎯 Основные возможности

### 📷 Recognition (Распознавание)
```
Загрузить фото
    ↓
Выбрать режим (1:N или 1:1)
    ↓
Анализ:
  ✓ Качество кадра
  ✓ Наличие лица
  ✓ Liveness проверка
  ✓ Поиск в базе
    ↓
Результат: ALLOW | DENY | RETRY | MANUAL_CHECK
```

### 🎥 Video (Обработка видео)
```
Загрузить видео
    ↓
Система:
  • Извлекает кадры
  • Оценивает качество
  • Выбирает лучший (quality gate)
  • Анализирует лучший кадр
    ↓
Выдает:
  ✓ Timeline всех кадров
  ✓ Таблицу каждого кадра
  ✓ Финальное решение
```

### 👤 Enrollment (Регистрация)
```
User ID + Фото
    ↓
Проверка:
  ✓ Качество
  ✓ Лицо найдено
  ✓ Liveness
    ↓
Результат:
  ✓ Пользователь добавлен
  ✓ Template создан
  ✓ Доступ разрешен
```

### 👥 Users (Пользователи)
```
Список всех пользователей:
  • User ID
  • Количество templates
  • Статус доступа
```

### 📊 Events (События)
```
Все попытки доступа:
  • Время
  • Пользователь
  • Решение
  • Similarity
  • Quality
    ↓
  Export to CSV
```
