# Tasks

This directory contains sequential tasks for solo-agent development.

Working rule:

1. Take only one task at a time.
2. Before starting, read `AGENTS.md`, `docs/PROJECT.md`,
   `docs/CONTRACTS.md`, `docs/CURRENT_STATE.md`, and the selected task file.
3. Implement only the current task scope.
4. Add or update tests together with code.
5. Run `scripts/check.ps1` when it exists.
6. Update `docs/CURRENT_STATE.md` at the end.
