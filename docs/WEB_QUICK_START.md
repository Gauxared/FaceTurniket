# Быстрый старт - Веб-интерфейс

Система готова к запуску. Вот как начать:

## Подготовка

```powershell
# 1. Установить зависимости (если еще не установлены)
pip install -r requirements.txt

# 2. Опционально: установить InsightFace для реального распознавания
# pip install insightface onnxruntime
```

## Запуск

### Режим разработки

```powershell
# Запустить веб-сервер с auto-reload
python -m uvicorn src.web_api.app:app --reload --host 0.0.0.0 --port 8000
```

Затем откройте браузер: **http://localhost:8000**

### Production режим

```powershell
# Запустить с несколькими workers
python -m uvicorn src.web_api.app:app --host 0.0.0.0 --port 8000 --workers 4
```

## Использование интерфейса

### 1️⃣ Вкладка "Распознавание" (распознавание фото)

1. Нажмите на область загрузки или перетащите фото
2. Выберите режим:
   - **1:N Identification** — поиск по всей базе
   - **1:1 Verification** — проверка против конкретного пользователя
3. Увидите:
   - Фото с аннотациями (качество, углы лица)
   - Результат распознавания (found/not found)
   - Решение доступа (ALLOW/DENY/RETRY/MANUAL_CHECK)
   - Метрики (similarity, quality score)

### 2️⃣ Вкладка "Видео" (обработка видео)

1. Загрузите видео файл
2. Система:
   - Извлечет кадры
   - Применит quality gate для выбора лучшего
   - Покажет timeline всех кадров
   - Выдаст финальное решение
3. Увидите:
   - Timeline с цветными полосками (зелёный=выбран, жёлтый=хорошо, оранжевый=низко, красный=нет лица)
   - Таблицу с деталями каждого кадра
   - Финальное решение по лучшему кадру

### 3️⃣ Вкладка "Регистрация" (регистрация пользователя)

1. Введите User ID (например: `user_004`)
2. Загрузите фото пользователя
3. Нажмите "Зарегистрировать пользователя"
4. Если успешно — пользователь добавлен в систему

### 4️⃣ Вкладка "Пользователи" (список пользователей)

Видит список всех зарегистрированных пользователей:
- User ID
- Количество шаблонов лиц
- Статус доступа (allowed/denied)

### 5️⃣ Вкладка "События" (логирование событий)

Все события доступа:
- Время события
- Пользователь (если найден)
- Решение (allow/deny/retry/manual_check)
- Reason (причина решения)
- Similarity score
- Quality score

Кнопки:
- **Refresh** — обновить список
- **Export CSV** — скачать как CSV для анализа

## Переключение провайдера

### Mock Provider (по умолчанию)

```powershell
# Явно задать mock
$env:FACE_PROVIDER = "mock"
python -m uvicorn src.web_api.app:app --reload --host 0.0.0.0 --port 8000
```

Преимущества:
- ✅ Работает без зависимостей
- ✅ Детерминированный (всегда одинаковый результат)
- ✅ Быстрый
- ❌ Не реальное распознавание лиц

### InsightFace Provider (реальное распознавание)

```powershell
# Установить InsightFace (первый раз)
pip install insightface onnxruntime

# Запустить с InsightFace
$env:FACE_PROVIDER = "insightface"
python -m uvicorn src.web_api.app:app --reload --host 0.0.0.0 --port 8000
```

Преимущества:
- ✅ Реальное распознавание лиц
- ✅ Работает с любыми фото
- ❌ Требует больше времени на обработку
- ❌ Требует установки дополнительных библиотек

## Тестовые пользователи (Mock Provider)

При использовании mock provider, предзагруженные пользователи:

- **user_001** — всегда находится, качество хорошо
- **user_002** — всегда находится, качество хорошо
- **user_003** — всегда находится, качество хорошо

Попробуйте загрузить фото с именем вроде:
- `user_001_good.jpg` → будет найден user_001
- `unknown.jpg` → не будет найден
- `low_quality.jpg` → качество низкое

## Структура результатов

### Quality Scores

```
Quality Score:     0-1 (чем выше, тем лучше)
Blur Score:        0-1 (чем выше, тем острее)
Brightness Score:  0-1 (чем выше, тем лучше освещено)
```

### Face Angles

```
Yaw:   -45 до +45°  (поворот влево-вправо)
Pitch: -30 до +30°  (наклон вверх-вниз)
Roll:  -30 до +30°  (наклон влево-вправо)
```

### Decision Badges

- 🟢 **ALLOW** — доступ разрешён
- 🔴 **DENY** — доступ запрещён
- 🟠 **RETRY** — попробуйте ещё раз (низкое качество)
- 🔵 **MANUAL_CHECK** — требуется проверка вручную (неоднозначный матч)

## Типичные сценарии

### Сценарий 1: Проверить работу с фото

1. Откройте вкладку **Распознавание**
2. Загрузите фото студента
3. Выберите **1:N Identification**
4. Система:
   - Проверит качество кадра
   - Проверит наличие лица
   - Проверит liveness
   - Найдёт похожего пользователя
   - Выдаст решение (allow/deny/etc)

### Сценарий 2: Проверить quality gate на видео

1. Откройте вкладку **Видео**
2. Загрузите видео с несколькими кадрами
3. Система:
   - Оценит каждый кадр
   - Выберет лучший (обычно середина)
   - Покажет timeline
   - Выдаст финальное решение

### Сценарий 3: Регистрация нового пользователя

1. Откройте вкладку **Регистрация**
2. Введите user ID (например: `student_001`)
3. Загрузите хорошее фото пользователя
4. Нажмите "Зарегистрировать пользователя"
5. После успеха — пользователь добавлен
6. Откройте вкладку **Пользователи** — пользователь должен появиться в списке
7. Теперь при распознавании он будет найден

### Сценарий 4: Просмотр истории событий

1. Откройте вкладку **События**
2. Видите все события доступа
3. Можете:
   - Обновить список (Refresh)
   - Экспортировать в CSV (Export CSV)
   - Анализировать метрики

## Решение проблем

### Ошибка: "Could not decode image"

- Убедитесь, что файл — это настоящее изображение
- Попробуйте другой формат (JPG, PNG, BMP)

### Ошибка: "InsightFace not available"

- Установите зависимости: `pip install insightface onnxruntime`
- Система автоматически вернётся к mock provider

### Медленная обработка видео

- Уменьшите разрешение видео
- Используйте более короткие видео (< 30 секунд)
- С InsightFace обработка медленнее, чем с mock

### Результаты не совпадают с ожидаемыми

- Проверьте качество фото (может быть слишком тёмно/светло)
- Убедитесь, что лицо хорошо видно и в фокусе
- Попробуйте с другой фотографией
