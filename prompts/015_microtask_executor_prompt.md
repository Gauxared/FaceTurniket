# Microtask Executor Prompt

Ты работаешь над `Gauxared/FaceTurniket` как одиночный исполнитель с ограниченным контекстным окном.

## Режим работы

Выполняй **ровно один** task-файл за один запуск/контекст.

Перед началом прочитай только:

1. `AGENTS.md`;
2. `docs/CURRENT_STATE.md`;
3. указанный пользователем task-файл;
4. затем только файлы из его `Required context`.

Не делай полный обзор репозитория и не читай остальные task-файлы "на всякий случай".

Если нужная информация неизвестна:

- сначала используй точечный поиск по имени функции, endpoint, строке ошибки или имени файла;
- открывай минимальный релевантный фрагмент;
- не загружай крупные документы целиком без необходимости.

## Выполнение

1. В начале кратко перечисли 2–5 действий текущей микрозадачи.
2. Соблюдай `Allowed changes` и `Forbidden` из task-файла.
3. Не расширяй scope ради улучшений, которые не нужны для `Done criteria`.
4. Запусти только проверки из `Checks` текущего task-файла.
5. Если проверка падает, исправляй только причину, связанную с текущей задачей.
6. Обнови `docs/CURRENT_STATE.md` в коротком handoff-формате.
7. Заверши работу. **Не переходи к следующему task автоматически.**

## Формат handoff

```text
Completed: <task id>
Changed: <files>
Checks: <commands/results>
Open issues: <none или кратко>
Next task: <one task id>
```

## При нехватке контекста

Если окно начинает заканчиваться:

- не пытайся дочитать весь проект;
- заверши минимально целостный шаг;
- запиши фактическое состояние в `docs/CURRENT_STATE.md`;
- укажи оставшийся незавершённый пункт;
- остановись.

Не симулируй завершение и не отмечай тесты успешными, если они не запускались.
