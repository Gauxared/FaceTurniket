# Executor Agent Prompt

Ты работаешь в локальном Python-проекте:

```text
D:\Kamenev_solo
```

Проект: система идентификации или верификации сотрудника/студента по фото лица
для принятия решения о проходе через турникет.

Это solo-agent workflow. Мультиагентная инфраструктура не используется.

## Перед началом любой задачи

Обязательно прочитай:

- `AGENTS.md`
- `docs/PROJECT.md`
- `docs/CONTRACTS.md`
- `docs/ITERATION_PLAN.md`
- `docs/CURRENT_STATE.md`
- конкретный файл задачи из `tasks/`

## Главные правила

- Выполняй только текущую задачу.
- Не делай широкий рефакторинг вне scope.
- Не добавляй реальные ML-зависимости до задачи `008_real_face_provider`.
- Не обучай модель распознавания лиц с нуля.
- Не храни реальные фото, персональные данные или реальные embeddings.
- Не смешивай ML, access decision, turnstile и event log в одном модуле.
- Face provider возвращает только `RecognitionResult`.
- Access module принимает итоговое решение о проходе.
- Turnstile module только исполняет решение.
- Event log только записывает событие.

## Рабочий цикл

1. Кратко сформулируй план.
2. Реализуй только требуемые изменения.
3. Добавь или обнови тесты, если задача требует код.
4. Запусти доступные проверки.
5. Исправь ошибки, если проверки падают.
6. Обнови `docs/CURRENT_STATE.md`.
7. В финальном ответе перечисли:
   - что изменено;
   - какие файлы затронуты;
   - какие проверки запускались;
   - что осталось следующим шагом.

## Проверки

Когда существует `scripts/check.ps1`, запускай:

```powershell
scripts/check.ps1
```

Если script еще не создан, запускай доступные проверки вручную или объясни,
почему пока нечего запускать.

Типовые проверки после появления кода:

```powershell
python -m pytest -q
python harness/run_all.py
```

## Definition of Done

Задача считается выполненной только если:

- сделано ровно то, что указано в task-файле;
- тесты и harness проходят, если они уже реализованы;
- `docs/CURRENT_STATE.md` обновлен;
- нет реальных ML-зависимостей раньше нужной итерации;
- нет реальных персональных или биометрических данных;
- следующий task ясно указан в `docs/CURRENT_STATE.md`.
