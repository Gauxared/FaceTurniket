Этот файл содержит правила для AI-агента, который разрабатывает проект в одиночном режиме.

Перед любой задачей агент должен прочитать:

AGENTS.md
docs/PROJECT.md
docs/CONTRACTS.md
docs/ITERATION_PLAN.md
docs/CURRENT_STATE.md
конкретный файл задачи из tasks/
Описание проекта

Проект — локальная Python-система идентификации или верификации сотрудника/студента по фото лица для прохода через турникет.

Система должна:

Получить изображение с камеры или из тестового файла.
Найти лицо.
Проверить качество кадра.
Проверить живость лица или использовать mock-liveness на MVP.
Получить embedding лица через готовое face-recognition решение.
Сравнить embedding с шаблонами пользователей.
Проверить права доступа.
Принять решение: allow, deny, retry или manual_check.
Сымитировать открытие турникета.
Записать событие в журнал.
Главные правила разработки
Не делать всю систему одним большим куском.
Работать маленькими итерациями через tasks/*.md.
Сначала писать mock-pipeline и harness, потом подключать реальное распознавание.
Не обучать модель распознавания лиц с нуля.
Готовое face-recognition решение подключать только через provider/adapter.
Сохранять MockFaceRecognitionProvider даже после подключения реального provider.
Не смешивать ML-логику, бизнес-логику доступа и работу с турникетом.
ML-модуль не имеет права открывать турникет.
Access-модуль принимает итоговое решение о проходе.
Не хранить реальные фото людей и персональные данные в репозитории.
Не использовать пол, возраст, расу, эмоции или похожие признаки для решения о доступе.
Не менять контракты из docs/CONTRACTS.md без обновления тестов и документации.
После изменений запускать scripts/check.ps1.
В конце каждой задачи обновлять docs/CURRENT_STATE.md.
Формат работы агента

Для каждой задачи агент обязан:

Прочитать AGENTS.md, docs/PROJECT.md, docs/CONTRACTS.md и файл задачи.
Кратко составить план.
Реализовать только указанную задачу.
Добавить или обновить тесты.
Запустить scripts/check.ps1.
Исправить ошибки, если проверки падают.
Обновить docs/CURRENT_STATE.md.
Кратко перечислить изменённые файлы.
Definition of Done

Задача считается выполненной только если:

реализовано только то, что указано в task-файле;
unit-тесты проходят;
harness-сценарии проходят;
публичные контракты не сломаны;
docs/CURRENT_STATE.md обновлён;
нет лишнего рефакторинга;
нет подключения реальных ML-библиотек раньше соответствующей итерации.
