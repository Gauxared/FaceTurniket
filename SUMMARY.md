## 🎯 Основные особенности

### 1. Recognition (Распознавание одного фото)
```
Загрузить фото
    ↓
Выбрать режим (1:N или 1:1)
    ↓
Система:
  - Проверяет качество (blur, brightness, angles)
  - Проверяет наличие лица и наличие одного лица
  - Проверяет liveness (живое ли лицо)
  - Ищет совпадение в базе
  - Выдаёт решение (ALLOW/DENY/RETRY/MANUAL_CHECK)
    ↓
Видишь результат с аннотациями
```

### 2. Video (Обработка видео)
```
Загрузить видео
    ↓
Система:
  - Извлекает 30 кадров
  - Оценивает качество каждого
  - Выбирает лучший через quality gate
  - Показывает timeline все кадров
    ↓
Видишь:
  - Цветной timeline (какие кадры хорошие)
  - Таблицу каждого кадра с деталями
  - Финальное решение по лучшему кадру
```

### 3. Enrollment (Регистрация пользователя)
```
Ввести User ID
    ↓
Загрузить фото
    ↓
Система:
  - Проверяет качество фото
  - Создаёт embedding/шаблон
  - Добавляет в базу
    ↓
Пользователь добавлен! Теперь может быть найден при распознавании
```

### 4. Users (Список пользователей)
```
Видишь всех зарегистрированных пользователей:
  - User ID
  - Количество шаблонов (одно лицо может иметь несколько фото)
  - Статус доступа (allowed/denied)
```

### 5. Events (Логирование событий)
```
Видишь все попытки доступа:
  - Время события
  - Пользователь (если найден)
  - Решение (allow/deny/retry/manual_check)
  - Причина решения
  - Similarity и quality scores
    ↓
Можешь экспортировать в CSV для анализа
```

## 🚀 Как начать

### Быстрый старт (30 секунд)

```powershell
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить веб-сервер
python -m uvicorn src.web_api.app:app --reload --host 0.0.0.0 --port 8000

# 3. Открыть в браузере
# http://localhost:8000
```

## 📱 Провайдеры

### Mock (По умолчанию)
- Работает без зависимостей
- Быстро
- Детерминированно (всегда одинаковые результаты)
- Подходит для тестов и демонстрации

### InsightFace (Опционально)
- Реальное распознавание лиц
- Медленнее, чем mock
- Требует: `pip install insightface onnxruntime`
- Подходит для production
